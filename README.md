# 📊 Interactive Sales Dashboard

An interactive sales analysis project built using Python, Pandas, Matplotlib, Seaborn, and Plotly. This project explores sales performance, product trends, data distributions, and correlations through visualizations and interactive dashboards.

## 🎯 Project Overview

The **Interactive Sales Dashboard** is designed to analyze sales data and present meaningful insights through charts and interactive visualizations.

The project demonstrates data cleaning, exploratory data analysis (EDA), statistical summaries, correlation analysis, and sales visualization using Python.

## 🚀 Project Objectives

* Analyze sales data using Pandas.
* Explore product-wise sales performance.
* Create statistical summaries.
* Visualize sales distributions and correlations.
* Build interactive charts and dashboards.
* Present insights through clear visualizations.

## 🛠️ Technologies Used

* **Python** — Data analysis and programming
* **Pandas** — Data manipulation and analysis
* **NumPy** — Numerical computations
* **Matplotlib** — Data visualization
* **Seaborn** — Statistical visualization
* **Plotly** — Interactive charts
* **Google Colab** — Notebook development
* **GitHub** — Project hosting and version control

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/singhnitish11/week-6-interactive-sales-dashboard.git
```

### 2. Navigate to the Project Folder

```bash
cd week-6-interactive-sales-dashboard
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Python Script

```bash
python dashboard.py
```

### 5. Open the Notebook

Open `dashboard.ipynb` in Google Colab or Jupyter Notebook.

Upload `sales_data.csv` if required, and run the notebook cells in order.
